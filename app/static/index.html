회사 위치 · 추천 설정

길찾기 출발점이 엉뚱하게 잡히면 좌표가 안 맞는 것입니다. 건물명으로 찾아서 고르면 위도·경도가 정확히 채워집니다.

식당 수집

네이버 지역검색으로 지역 키워드 주변 식당을 모읍니다. 반경 밖은 자동으로 걸러집니다. '리뷰·영업시간 채우기'는 영업시간을 구글 Places 공식 API로 가져와 점심에 문 여는 곳인지 자동으로 판정하고, '음식이 맛있어요' 비율은 네이버에서 채웁니다.

네이버 API 키 (선택)

넣으면 식당마다 좌표를 받아와 회사에서의 거리를 채웁니다. 안 넣어도 붙여넣기 등록·추천·별점은 그대로 됩니다. NAVER API HUB 에서 Application → 인증 정보를 열면 나옵니다.

네이버 지도 목록 붙여넣기

네이버 지도에서 음식점으로 검색한 목록을 드래그해서 그대로 복사·붙여넣기 하세요. 별점·주소·리뷰·광고가 섞여 있어도 상호명과 업종만 알아서 골라냅니다. 좌표와 회사에서의 거리는 등록할 때 자동으로 채워집니다. 영업시간 → 평일 12시 필터까지 걸어 두면 점심 장사하는 곳만 걸러집니다.

여러 번 나눠서 붙여넣을 거라면 이 체크는 꺼 두세요. 켜면 두 번째 묶음을 올릴 때 첫 번째 묶음이 전부 '점심 안 함'이 됩니다. 등록은 계속 쌓이는 방식이니 그냥 나눠서 여러 번 올리시면 됩니다.
