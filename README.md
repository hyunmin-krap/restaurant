# 🍚 오늘 뭐 먹지?

회사 주변 식당을 랜덤으로 뽑아 주는 사내용 점심 추천기.
아무도 먼저 말을 못 꺼내서 결국 늘 가던 데 가는 문제를 해결하려고 만들었습니다.

- 회사 좌표 기준 **반경 N m 이내** 식당만 후보로 둡니다.
- 한 번에 **3곳**(설정 가능)을 뽑되, **세부 분류가 절대 겹치지 않습니다.**
  돈가스 두 곳, 국밥 두 곳이 같이 나오는 일이 없습니다.
- 네이버 방문자 리뷰의 **'음식이 맛있어요' 비율**을 함께 보여줍니다. (선택 기능 — 아래 한계 참고)
- 다녀온 뒤 **사내 별점**을 남기면 다음 추천 가중치에 반영됩니다.
- 별로였던 곳은 **'다시 안 보기'** 로 후보에서 뺄 수 있고, 언제든 되돌릴 수 있습니다.
- 최근에 뽑힌 곳은 한동안 덜 나오고, 아직 안 뽑힌 곳에는 가산점이 붙어서
  **모르던 식당이 자연스럽게 걸립니다.**
- 카페·술집·배달전문은 수집 단계에서 빠지고, 저녁 장사만 하는 집은 **'점심 안 함'** 으로
  한 번 표시해 두면 팀 전체 추천에서 빠집니다.
- 카드에서 **네이버 지도**·**길찾기**(회사→식당 도보)로 바로 넘어갑니다.
  모바일에서는 네이버 지도 앱이 있으면 앱으로 열립니다.

의존성이 없습니다. 파이썬 3.10+ 만 있으면 됩니다. (pip install 필요 없음)

## 실제로 쓰기

### 1. 네이버 검색 API 키 발급

<https://developers.naver.com/apps> → 애플리케이션 등록 → **검색** API 선택.
발급받은 값을 `.env` 에 넣습니다.

```ini
NAVER_CLIENT_ID=발급받은_ID
NAVER_CLIENT_SECRET=발급받은_SECRET
```

무료이고 하루 25,000회까지 씁니다. 수집은 한 번에 60회 정도만 쓰므로 넉넉합니다.

### 2. 회사 좌표 넣기

기본값은 **공덕역** 좌표(37.54306, 126.95111)로 들어가 있습니다.
건물 정문 기준으로 더 정확히 맞추려면 둘 중 하나를 쓰세요.

```bash
python3 scripts/find_coords.py "공덕역 신원빌딩"
```

또는 네이버 지도에서 건물을 클릭하면 주소창이
`.../?c=126.95111,37.54306,17,0,0,0,dh` 처럼 바뀌는데, 여기서 **앞이 경도, 뒤가 위도**입니다.

```ini
OFFICE_NAME=신원빌딩 (공덕역 4번출구)
OFFICE_LAT=37.54306
OFFICE_LNG=126.95111
SEARCH_RADIUS_M=500      # 도보 500m ≈ 7분
RECOMMEND_COUNT=3
```

반경 500m 기준이면 역 중심과 건물 정문의 수십 m 차이는 결과에 거의 영향이 없습니다.

좌표·반경은 서버를 켠 뒤 **설정 탭**에서 바꿔도 됩니다. (그 값이 `.env` 보다 우선합니다.)

### 3. 주변 식당 수집

```bash
python3 scripts/sync_places.py --area 역삼동
```

`--area` 는 검색에 쓸 지역 키워드입니다 (`역삼동`, `판교역`, `여의도` 등).
`역삼동 돈가스`, `역삼동 국밥` … 처럼 60여 개 음식 키워드로 나눠 검색한 뒤,
받아온 좌표를 회사 좌표와 비교해 **반경 밖은 버립니다.**
서버 **설정 탭 → 주변 식당 수집** 버튼으로도 같은 일을 합니다.

### 4. 켜기

```bash
python3 -m app
```

데이터는 `data/lunch.db` (SQLite) 한 파일이라 백업도 이 파일만 복사하면 됩니다.

### 5. 회사 사람들과 같이 쓰기

**같은 사무실 와이파이(사내망)를 쓰고 있으면 추가 설정이 거의 없습니다.**
서버를 켠 PC의 사내 IP를 알아내서 그 주소를 공유하면 됩니다.

```bash
# 서버를 켠 PC에서 (macOS / Linux)
ipconfig getifaddr en0     # 예: 192.168.0.14
hostname -I | awk '{print $1}'
# Windows
ipconfig                   # IPv4 주소 항목
```

동료들은 브라우저에서 `http://192.168.0.14:8000` 으로 들어옵니다.
`HOST=0.0.0.0` 이 기본값이라 별도 설정은 필요 없습니다.

체크할 것 몇 가지:

| 확인 | 내용 |
| --- | --- |
| **PC가 켜져 있어야 함** | 서버를 띄운 PC가 꺼지거나 잠자면 접속이 끊깁니다. 늘 켜 두는 PC나 사내 서버가 좋습니다. |
| **방화벽** | macOS·Windows 방화벽이 8000 포트를 막을 수 있습니다. 처음 실행할 때 뜨는 허용 창에서 승인하세요. |
| **같은 네트워크여야 함** | 게스트 와이파이는 기기 간 통신을 막아 두는 경우(AP isolation)가 많습니다. 안 되면 사내 와이파이로 붙어 보세요. |
| **사설 IP는 바뀔 수 있음** | 공유기가 IP를 다시 나눠 주면 주소가 달라집니다. 공유기 설정에서 그 PC에 고정 IP를 주면 편합니다. |

집이나 외부에서도 열려면 공유기 포트포워딩이 필요한데, **권장하지 않습니다.**
이 앱에는 로그인이 없어서 인터넷에 그대로 노출하면 누구나 들어와 별점과 제외 목록을 건드릴 수 있습니다.
사내망 안에서만 쓰거나, 꼭 필요하면 사내 VPN을 통해 붙으세요.

## '음식이 맛있어요' 비율에 대한 정직한 이야기

네이버는 이 지표를 **공개 API 로 주지 않습니다.** 지역검색 API 로 받을 수 있는 건
상호·주소·분류·좌표까지입니다. 그래서 이 기능은 플레이스 웹페이지가 쓰는
내부 GraphQL 엔드포인트를 그대로 호출하는 방식으로 넣었고, 기본값은 **꺼짐**입니다.

```ini
ENABLE_PLACE_REVIEW_SCRAPE=1   # 켜려면
```

```bash
python3 scripts/sync_places.py --taste --limit 80
```

- 네이버가 스키마를 바꾸거나 막으면 **언제든 동작을 멈춥니다.** (그래도 앱은 정상 동작하고, 해당 칸만 '지표 없음'으로 비어 있습니다.)
- 서비스 약관상 회색지대입니다. 사내 소규모 사용을 전제로 두세요.
- 대안으로 **설정 탭이나 API 로 비율을 손으로 넣을 수 있습니다.** 자주 가는 곳 몇 곳만
  한 번 채워 두면 추천 품질에는 충분합니다.

```bash
curl -X POST localhost:8000/api/taste \
  -H 'Content-Type: application/json' \
  -d '{"place_id":"naver:한터 돼지국밥|서울 강남구 ...","ratio":91,"total":402}'
```

## 추천 규칙

균등 랜덤이 아니라 가중 랜덤입니다. 네 가지를 곱해서 가중치를 만듭니다.

| 요소 | 영향 | 설명 |
| --- | --- | --- |
| 맛있어요 비율 | 0.4 ~ 1.6배 | 리뷰 수가 적으면 비율을 덜 믿습니다 (30건 미만이면 영향 축소) |
| 사내 별점 | 0.35 ~ 1.7배 | 베이지안 보정. 1~2명만 매긴 별점으로는 순위가 크게 안 흔들립니다 |
| 최근 노출 | 0.05 ~ 1.25배 | 오늘 뽑힌 곳은 거의 안 나오고, 7일·14일이 지나며 회복. **한 번도 안 뽑힌 곳은 1.25배** |
| 거리 | 0.75 ~ 1.25배 | 가까울수록 유리. 코앞으로 쏠리지 않게 완만한 곡선(지수 1.5)을 씁니다 |

거리 곡선은 `1.25 - 0.5 × (거리/반경)^1.5` 입니다. 가까운 구간끼리는 차이가 작아서
바로 앞 몇 집으로 쏠리지 않고, 반경 끝으로 갈수록 확실히 떨어져 먼 곳과 동등해지지도 않습니다.
반경 500m 기준으로 **50m 지점이 500m 지점보다 약 1.65배** 자주 뽑힙니다
(`tests/test_recommender.py::TestDistanceWeighting` 에서 이 범위를 고정하고 있습니다).

그다음 [Efraimidis–Spirakis 비복원 가중 추출](https://doi.org/10.1016/j.ipl.2005.11.003)로
N개를 뽑으면서 두 가지 제약을 겁니다.

1. **세부 분류는 절대 안 겹칩니다.** `돈까스`·`돈가스`·`카츠`·`규카츠`,
   `순대국밥`·`돼지국밥`·`순댓국` 처럼 표기만 다른 음식은 하나로 묶여
   **74가지 세부 분류**로 정리돼 있습니다 (`app/categories.py`).
   반대로 부위별로 쪼개면 의미가 없는 것(삼겹살·목살·갈매기살)은 `고깃집` 하나로 묶습니다.
2. **대분류(한식/중식/일식…)도 되도록 안 겹칩니다.** 후보가 부족하면 이 조건만 풉니다.

> **겹침 금지는 한 번의 추천 안에서만 적용됩니다.**
> A돈가스가 오늘 나왔다고 B돈가스가 영영 안 나오는 게 아닙니다.
> 다시 뽑으면 다른 돈가스집이 그 자리에 올 수 있습니다.
> (같은 *가게*가 연달아 나오는 것만 '최근 노출' 가중치로 억제합니다.)

세부 분류가 겹치지 않게 3곳을 못 채우면 **억지로 채우지 않고 2곳만 보여줍니다.**
그럴 땐 화면에 안내가 뜨니 반경을 넓히거나 제외 목록을 확인하세요.

## 점심에 갈 수 있는 곳만 남기기

세 단계로 거릅니다. 앞의 둘은 자동입니다.

1. **업종 자동 제외** — 카페·디저트·베이커리, 술집·이자카야·와인바, 배달/포장 전문,
   그리고 애초에 식당이 아닌 업종을 카테고리와 상호명으로 걸러 냅니다.
   단 브런치집·구내식당처럼 카페로 분류되지만 한 끼가 되는 곳은 예외로 남깁니다.
2. **영업시간 자동 판정** — 네이버 지도에서 [음식점 → 영업시간 → 평일 12시]로 필터를 거는 것과
   같은 판정을 코드로 합니다 (`app/hours.py`). 평일 12:00~13:00 에 실제로 열려 있는지 보고,
   저녁 장사만 하는 집과 점심에 브레이크타임이 걸린 집을 뺍니다.
   요일별 영업시간·브레이크타임·정기휴무를 읽으며, 평일 중 절반 이상 점심에 열려 있으면 통과입니다.

   ```bash
   python3 scripts/sync_places.py --enrich --limit 80
   ```

   **영업시간은 구글에서 가져옵니다** — 아래 [영업시간은 왜 구글인가](#영업시간은-왜-구글인가) 참고.

3. **사람이 표시** — 자동 판정이 못 찾은 곳이 남을 수 있습니다.
   그럴 땐 카드의 **'🕛 점심 안 함'** 버튼으로 표시하면 팀 전체 추천에서 빠집니다.
   손으로 표시한 값은 자동 판정이 덮어쓰지 않습니다.

### 네이버 지도 목록을 통째로 붙여넣기

자동 판정이 막혔을 때 가장 빠른 길입니다.
네이버 지도에서 **음식점 → 영업시간 → 요일·시간을 평일 12시**로 걸면 점심 장사하는 곳만 나옵니다.
그 목록의 상호명을 설정 탭에 한 줄에 하나씩 붙여넣으면 좌표·분류가 자동으로 채워지고
전부 '점심 영업'으로 표시됩니다. `이 목록에 없는 기존 식당은 점심 안 함으로 표시`를 함께 켜면
붙여넣은 목록이 곧 점심 후보 전부가 됩니다.

### 구내식당

네이버 지도에 등록된 구내식당은 `구내식당` 이라는 자체 분류로 잡혀서 그대로 후보가 됩니다.
지도에 없는 사내 구내식당(건물 지하 등)은 설정 탭의 **직접 추가**에서
분류를 `음식점>구내식당` 으로 넣으면 됩니다. 좌표를 비워 두면 거리 계산에서 빠지고
반경과 무관하게 늘 후보로 남습니다.

```bash
curl -X POST localhost:8000/api/lunch \
  -H 'Content-Type: application/json' \
  -d '{"place_id":"naver:마포 돼지국밥|서울 마포구 ...","open":false}'
```

## 영업시간은 왜 구글인가

식당 목록·분류·좌표·'맛있어요' 비율은 **네이버**에서 가져옵니다. 한국 식당은 네이버가 압도적입니다.
그런데 **네이버 지역검색 API 는 영업시간을 주지 않습니다.** 구글은 공식 API 로 줍니다.
그래서 **영업시간 하나만 구글로 보충**합니다.

```ini
GOOGLE_MAPS_API_KEY=발급받은_키
GOOGLE_MONTHLY_CALL_LIMIT=900
```

<https://console.cloud.google.com> 에서 **Places API (New)** 를 켜고 키를 발급하세요.

### 돈이 나가나요

**결제 계정(카드) 등록은 필수입니다.** 무료 한도 안에서만 써도 구글은 키 발급에 결제 계정을 요구합니다.
가입할 때 보이는 `$300 / 90일 무료 체험판`은 별개이고, 그게 끝나도 아래 무료 한도는 매달 계속됩니다.

2025년 3월부터 예전의 `$200 통합 크레딧`이 없어지고 **SKU별 무료 건수**로 바뀌었습니다.
영업시간(`regularOpeningHours`)은 **Enterprise SKU** 라 무료 한도가 **월 1,000건**으로 가장 빡빡합니다.

그런데 이 앱이 실제로 쓰는 양은 그보다 훨씬 적습니다.

| | 호출 수 |
| --- | --- |
| 반경 500m 안 식당 (보통) | 50 ~ 150곳 |
| 최초 1회 채우기 | 식당 수 만큼 (예: 100건) |
| 이후 갱신 | 새로 생긴 곳 + 갱신할 곳만 |
| 월 1회 전체 갱신해도 | 약 100건 = **무료 한도의 10%** |

식당 한 곳당 한 번만 부르고 결과를 DB에 저장하기 때문입니다. 사람이 버튼을 눌러야 도는 것이지
추천할 때마다 부르는 게 아닙니다.

**그래도 사고를 막는 장치를 두 겹으로 두세요.**

1. **앱 자체 상한** (기본 월 900건) — `GOOGLE_MONTHLY_CALL_LIMIT` 로 조절합니다.
   한도에 걸리면 구글 호출을 멈추고 네이버 쪽으로 조용히 넘어갑니다.
   설정 탭에 `구글 호출 2026-09: 123 / 900건 사용` 처럼 이번 달 누적이 표시됩니다.
2. **구글 콘솔 할당량 상한** — Google Cloud Console → API 및 서비스 → Places API → 할당량에서
   일일 요청 상한을 걸어 두세요. 이건 구글 쪽에서 막는 것이라 코드에 버그가 있어도 뚫리지 않습니다.
   예산 알림(Billing → Budgets & alerts)도 함께 걸어 두면 안전합니다.

**카드를 등록하고 싶지 않으면 구글을 안 쓰면 됩니다.** 영업시간 판정 경로가 넷이라
나머지 셋(네이버 플레이스 · 목록 붙여넣기 · 수동 표시)만으로도 앱은 그대로 동작합니다.

| | 담당 소스 | 성격 |
| --- | --- | --- |
| 식당 목록·분류·좌표 | 네이버 지역검색 | 공식 API, 무료 |
| '음식이 맛있어요' 비율 | 네이버 플레이스 | **비공식** 경로, 막힐 수 있음 |
| **영업시간 (점심 영업 여부)** | **구글 Places** | **공식 API**, 종량제 |

한 번 조회하면 `google_place_id` 를 저장해 두고, 다음 갱신 때는 검색을 건너뛰고
그 ID 로 바로 조회합니다. 더 싸고 정확할 뿐 아니라 검색과 상세조회가 **서로 다른 SKU** 라
무료 한도를 나눠 쓰는 효과도 있습니다.

구글 키가 없으면 네이버 플레이스(비공식)로 넘어가고, 그것도 실패하면 붙여넣기·수동 표시가 남습니다.
**세 경로 중 하나만 되면 됩니다.**

구글이 브레이크타임을 별도 필드로 주지 않고 하루를 여러 구간으로 쪼개 주는 점(11:00~15:00 + 17:00~21:00)도
그대로 처리합니다 — 그 요일의 구간 중 하나라도 점심을 덮으면 점심 영업으로 봅니다.

## 네이버 지도로 넘어가기

각 카드에 두 개의 링크가 있습니다.

- **네이버 지도** — 플레이스 ID 를 알면 상세 페이지로, 모르면 상호+주소 검색으로 엽니다.
  모바일에서는 `nmap://` 스킴으로 앱을 먼저 시도하고, 앱이 없으면 웹으로 넘어갑니다.
- **길찾기** — 회사 좌표에서 식당까지 **도보 경로**로 바로 엽니다.

지도 URL 은 네이버 지도 웹의 현재 주소 형식(`map.naver.com/p/...`)을 씁니다.
네이버가 형식을 바꾸면 `app/service.py` 의 `naver_map_url` / `naver_directions_url` 만 고치면 됩니다.

## 별점과 제외

- 별점은 **사람 이름별로 1개**입니다. 같은 사람이 다시 매기면 덮어씁니다.
- 이름은 브라우저에 기억되므로 매번 입력할 필요 없습니다.
- **기록 탭**에서 지난 추천을 보고 다녀온 곳에 바로 별점을 남길 수 있습니다.
- **다시 안 보기**는 팀 전체 기준입니다. 이유를 남겨 두면 나중에 왜 뺐는지 알 수 있고,
  설정 탭의 제외 목록에서 되돌릴 수 있습니다.
- 제외하거나 '점심 안 함'을 눌러도 **나머지 카드는 그대로 있습니다.** 그 카드만 흐려지고
  `되돌리기` / `다른 곳 보기` 로 바뀝니다.
- **🔄 다른 곳** 버튼은 그 자리 하나만 다른 식당으로 바꿉니다. 옆 카드의 분류와 겹치지 않는
  곳으로 골라 옵니다.
